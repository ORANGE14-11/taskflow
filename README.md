## ✨ Features

| Feature | Description |
|---------|-------------|
| 📋 **Kanban Board** | Drag-and-drop task management with 4 status columns |
| 📊 **Analytics Dashboard** | Visual charts showing task distribution and progress |
| 📅 **Calendar View** | See tasks organized by due date |
| 📝 **List View** | Traditional table view of all tasks |
| 🌙 **Dark Mode** | Toggle between light and dark themes |
| 🔍 **Search** | Quickly find tasks by title, description, or tags |
| 💾 **Local Storage** | Data persists in browser storage |
| 📱 **Responsive** | Works on desktop, tablet, and mobile |
